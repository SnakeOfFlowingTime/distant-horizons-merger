# distant-horizons-merger
little thing i made to merge two distant horizons (the minecraft mod) sqlite files, even has a very simple ui.

using is simple, just execute it, choose the main file, then choose the secondary file, then click merge, and it will tell you when it's done via the text on the submit button changing, after that just close the window and you're good to go.

please backup your files before doing this, in theory it should work, the code does, haven't tested due to the lack of distant horizons files from the same server.
